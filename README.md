# Shorts 9:16 Video Editor 🎬

[![Deploy to GitHub Pages](https://github.com/actions/starter-workflows/actions/workflows/pages.yml/badge.svg)](https://github.com)
[![License: All Rights Reserved](https://img.shields.io/badge/License-All_Rights_Reserved-red.svg)](README.md#利用規約--著作権--無断転載二次配布について)
[![Framework: React 19 + Vite](https://img.shields.io/badge/Framework-React_19_+_Vite-61DAFB.svg)](https://vitejs.dev)

YouTube Shorts、TikTok、Instagram リール（9:16 縦長動画）の編集・加工に特化したブラウザ完結型のWeb動画エディタです。  
外部サーバーへの動画アップロードや重量ライブラリ（FFmpeg.wasm等）を一切使用せず、**HTML5 Canvas API** と **MediaRecorder API**、**Web Audio API** のみで高速に動作します。

---

## 📱 主な機能

- **9:16 縦長プレビュー＆エディタ**
  - フルHD（1080×1920）の高品質キャンバスレンダリング。
  - 横長動画や通常アスペクト比の動画も、自動で中央配置＆最適化。
  - ローカル動画（MP4 / WebM / QuickTime / MOV等）のドラッグ＆ドロップ読み込み。
  - 音声付きテストサンプル動画のワンクリック即時生成機能。
- **テキスト＆ウォーターマーク（透かしスタンプ）重ね合わせ**
  - キャンバス上での**直感的なドラッグ＆ドロップ移動**。
  - プリセット透かしスタンプ（「無断転載禁止」「転載厳禁」「SAMPLE」「Shorts / TikTokバッジ」など）。
  - カスタムテキスト装飾（フォントサイズ、文字色、縁取り色、背景プレート色・角丸など）。
  - チャンネルロゴや透過PNG画像の重ね合わせ機能。
  - 表示開始秒〜終了秒のタイムライン制御、不透明度、スケール、回転。
- **カメラワーク演出（ズームイン / ズームアウト）**
  - 指定区間（開始秒〜終了秒）での自動ズームアニメーション（イージング指定可能）。
  - 注目させたい部分を簡単にクローズアップ。
- **カラーグレーディング・フィルター**
  - プリセット（通常、白黒・モノクロ、セピア、高コントラスト、鮮やか、シネマティック）。
  - 明るさ、コントラスト、彩度、色相回転、ブラーの微調整。
- **動画エクスポート（MP4 / WebM）**
  - キャンバス映像と元動画の音声を完全同期合成。
  - プログレスバー付きで高速レンダリング＆ワンクリック保存。
- **単一HTMLファイル（In-lined CSS / JS）対応**
  - アプリ内の「単一HTMLコード」から、外部依存が一切ない単一の `.html` ファイルを保存可能。
  - ダブルクリックするだけで、オフライン環境でも完全動作します。

## 🌐 GitHub Pages（画面が真っ白になる場合の解決手順）

React (Vite) プロジェクトを GitHub Pages で公開する際、**初期設定のまま「Deploy from a branch > main / (root)」を選ぶと、未コンパイルの TypeScript コード (`/src/main.tsx`) がそのまま読み込まれてブラウザが実行できず画面が真っ白（404エラー）になります。**

本リポジトリでは**すでに修正・ビルド済みのファイル（`/docs` および GitHub Actions 設定）を完備**していますので、以下のどちらか**1つ**を行うだけで正常に表示されます。

---

### 【方法A（最もおすすめ・1分で解決）】 `/docs` フォルダからの配信に切り替える

リポジトリ内に完全ビルド済みの `/docs` フォルダ（Jekyll無効化 `.nojekyll` 付き）を用意しています。GitHub Actions の待機時間なしですぐに反映されます。

1. GitHub リポジトリ（`testman40/video-editor-tool`）の **[Settings]** タブを開きます。
2. 左メニューの **[Pages]** をクリックします。
3. **「Build and deployment」** の設定を以下のように指定します：
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`（または `master`）
   - **Folder**: `/docs` **← ここを `/(root)` から `/docs` に変更！**
4. **[Save]** をクリックします。
5. 数分後に `https://testman40.github.io/video-editor-tool/` を再読み込み（Ctrl + F5 または Shift + リロード）すると、正常にエディタ画面が表示されます！

---

### 【方法B】 GitHub Actions による自動ビルド＆デプロイを使う

`.github/workflows/deploy.yml` が含まれているため、GitHub 側でビルドを自動実行させることも可能です。

1. GitHub リポジトリの **[Settings]** > **[Pages]** を開きます。
2. **「Build and deployment」** の **「Source」** ドロップダウンを、`Deploy from a branch` から **「GitHub Actions」** に変更します。
3. リポジトリ上部の **[Actions]** タブを開き、「Deploy to GitHub Pages」ワークフローが緑色のチェックマーク（完了）になるのを待ちます。
4. 完了後、サイトが正常に表示されます。

---

### 🛠️ 本リポジトリで適用済みの対策

- **`docs/` フォルダの自動同期**: `npm run build` 実行時に `dist` と `docs` が同時に最新ビルドで生成されます。
- **`public/.nojekyll` / `docs/.nojekyll`**: GitHub Pages 標準の Jekyll 処理を無効化し、アンダースコア付きファイルやViteアセットを直接配信。
- **`vite.config.ts` (`base: './'`)**: リポジトリ名サブパス（`/video-editor-tool/`）に依存しない相対リンク指定。
- **フォールバックリダイレクト**: 万が一ルートの `index.html` が読み込まれた場合でも、スクリプトエラーを検知して自動で `./docs/` へリダイレクトする復旧スクリプトを内蔵。
- **エラーバウンダリ（ErrorBoundary）**: ブラウザ差異によるランタイムエラー発生時も白画面にならず、復旧用リロードUIを表示。

## 💻 ローカル環境での起動方法

### 必要環境
- Node.js 18.0.0 以上
- npm / pnpm / bun

### 起動手順

```bash
# 依存関係のインストール
npm install

# 開発用ローカルサーバーの起動 (http://localhost:3000)
npm run dev

# 本番用静的ファイルのビルド (/dist に出力)
npm run build

# ビルド成果物のプレビュー確認
npm run preview
```
